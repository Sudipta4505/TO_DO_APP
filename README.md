# To-Do List

A simple browser-based to-do list built with HTML, CSS, and JavaScript. Add tasks, mark them complete, and delete them. Tasks are saved in your browser using `localStorage`.

## Run locally

Open `todo.html` in a web browser. No installation or build step is required.

## Files

- `todo.html` - app structure
- `todo.css` - styles
- `todo.js` - task behavior and local storage
